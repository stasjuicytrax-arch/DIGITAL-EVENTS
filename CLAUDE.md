# CLAUDE.md — правила проекта DIGITAL EVENTS

Сайт креативного бюро развлечений DIGITAL EVENTS (Пермь). Слоган: «Технологии развлечений».

## Перед любой работой
1. Прочитай `TZ.md` (что делаем) и `DESIGN.md` (как это должно выглядеть).
2. Промты компонентов 21st.dev лежат в `prompts/` (список и статус в `prompts/README.md`).
3. Референсы лежат в `Referens/`.

## Скиллы (обязательно)
- **Impeccable**: `/impeccable init` один раз на старте; **critique** после каждого блока; **slop-проверка + polish** перед каждым пушем.
- **Taste Skill**: `design-taste-frontend` и `high-end-visual-design` при любых визуальных решениях.
- **awesome-design-md**: сверка `DESIGN.md` перед стартом вёрстки.

## Git
- Репозиторий: https://github.com/stasjuicytrax-arch/DIGITAL-EVENTS (ветка `main`).
- **Пуш после каждого законченного блока**, чтобы заказчик видел процесс. Коммиты: `feat(<section>): …`, `fix: …`, `chore: …`.
- Порядок блоков и шагов: `TZ.md §12`.

## Жёсткие правила
- Стек: Vite + React + TS + Tailwind 4 + shadcn-структура + three.js/R3F + GSAP + Lenis.
- Только токены из `DESIGN.md §13`, никаких «случайных» цветов и отступов.
- Лайм `#B6FC46` — сигнал, а не фон (≤ 2% площади).
- Не упоминать и не верстать «Интернет-маркетинг».
- Не выдумывать цифры, отзывы и клиентов.
- Одновременно максимум один активный WebGL-контекст; сцены паузятся вне экрана.
- Каждый эффект должен иметь режим для mobile и `prefers-reduced-motion`.
- Тексты только в `src/content/`, на русском, с неразрывными пробелами (типограф).
- Работа идёт в облачной сессии Claude Code (вкладка «Код» на claude.ai), репозиторий клонирован в сессию. Сеть ограничена: пакеты npm ставятся, а сайты вроде 21st.dev могут быть недоступны. Поэтому код компонентов брать из `prompts/`. Если нужного промта нет — остановись и попроси заказчика добавить его в `prompts/`.
- Проверку вёрстки делать через Playwright (Chromium уже установлен): скриншоты desktop 1440 и mobile 375 после каждого блока.
